**Verdict rules used here (SFD v1.0):**

- **STRONG** = the test asserts the exact preconditions + stimulus + expected of the case on a fresh, isolated deterministic fixture; failing the test would mean the case fails.
- **ADJACENT** = the test proves a closely related concern but not the literal case stimulus; the test is a partial witness.
- **WEAK** = the test exercises one path of a multi-path case; not a complete witness.

**No test → no transition.** A case is left at `specified_not_executed` unless a test above proves it.
