# FR-PHENOSDK-006: phenoSDK Wave A Contracts (SDD)

## Description

Extract stable ports and public DTOs from `pheno/ports` into versioned contract artifacts for Phenotype polyglot clients.

## Goal

Versioned contracts consumable by TypeScript, Go, and other language clients.

## Acceptance Criteria

- [ ] Inventory of port modules and adapter coupling
- [ ] Published contract format chosen (OpenAPI, protobuf, or JSON Schema)
- [ ] One downstream consumer PoC (TS or Go generated client)
- [ ] Contracts versioned and published

## Out of Scope

Moving adapter implementations or CLI in this wave.
