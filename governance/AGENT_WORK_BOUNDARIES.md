# AgilePlus Agent Work-Maze Boundaries

Agents work against accepted FRs and a bounded execution frontier.

Every assignment identifies FRs, parent feature/journey, stage target, dependencies, work package, claim/worktree, source scope, forbidden scope, acceptance/oracle intent, evidence and growth disposition.

Agents MUST NOT:
- invent accepted product scope;
- bypass claims/leases or another worker's dirty state;
- weaken their own acceptance/gate to pass;
- equate a closed WP/PR with product acceptance;
- silently create a competing Tracera product-state machine;
- turn optional integrations into core scope because code exists.

Prioritize work that closes stage blockers, features and journeys rather than adding shallow breadth.

Temporary adapters/prototypes require bounded replacement/migration debt.
