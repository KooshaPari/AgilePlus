# Specification: governance

Governance templates and configuration for the Phenotype organization.

## Overview

Repository containing governance templates, cliff configuration, and mise tooling
for managing organizational policies and conventions.

## Contents

- `templates/` - Reusable governance templates
- `cliff.toml` - Conventional commit configuration
- `mise.toml` - Developer toolchain management

## Usage

Templates in this repo are referenced by other repositories via symlinks.
