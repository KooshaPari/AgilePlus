| 80-82 | (3-line `with:` block: only `GITHUB_TOKEN`) | (8-line `with:` block: `GITHUB_TOKEN` + `coverage-path: python` + comment) |

```yaml
- name: Comment coverage on PR
  if: github.event_name == 'pull_request'
  uses: py-cov-action/python-coverage-comment-action@v4.5
  with:
      GITHUB_TOKEN: ${{ github.token }}
      # coverage is generated by `coverage run -m pytest` inside python/,
      # so the raw .coverage SQLite data file is at python/.coverage (not
      # at the workspace root). The action defaults to .coverage at the
      # repo root and silently fails to find it. Setting coverage-path
      # to the directory containing the data makes the action look at
      # python/.coverage, python/coverage.xml, python/coverage.json.
      coverage-path: python
```

Parameter verification: confirmed against `py-cov-action/python-coverage-comment-action@v4.5/action.yml` on GitHub. The action's input is named `COVERAGE_PATH`; GitHub Actions input matching is case-insensitive, so `coverage-path: python` (the YAML key) is correctly bound to `COVERAGE_PATH=python` (the env var the docker image reads). Default value is `"."` (the repo root), which is why all 5 of 6 open PRs fail today.
