# Dashboard

The AgilePlus Dashboard provides a visual interface for managing projects, features, work packages, and services.

## Features

- **Kanban Board**: Visualize work package workflow
- **Service Controls**: Start, stop, and monitor services
- **Project Overview**: Track feature progress across projects
- **Agent Status**: Monitor active agent sessions
