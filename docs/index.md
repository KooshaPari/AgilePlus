# AgilePlus Documentation

Cross-repo documentation and architectural decisions for the AgilePlus project management system.

## Structure

- **[Dashboard](./dashboard/)** - Visual interface documentation
- **[CLI](./cli/)** - Command-line interface reference
- **[API](./api/)** - REST API documentation
- **[Guide](./guide/)** - Getting started and how-to guides
- **[ADR](./adr/)** - Architecture Decision Records
- **[Specs](./specs/)** - Feature specifications

## Navigation

Use the sidebar to browse feature documentation. Each feature includes:
- Visual demonstrations (GIFs/screenshots)
- Usage instructions
- API reference (if applicable)
- Links to specifications and related features
