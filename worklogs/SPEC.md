# Specification: worklogs

Worklog repository for tracking research, decisions, and findings.

## Overview

Central repository for agent worklogs documenting research completions,
architectural decisions, duplication findings, and work status.

## Contents

- Remediation reports (batch*-repo-remediation.md)
- Phase completion reports
- Final reports
- Category-specific worklogs

## Categories

- ARCHITECTURE - ADRs, library extraction
- DUPLICATION - Cross-project duplication
- DEPENDENCIES - External deps, forks
- INTEGRATION - External integrations
- PERFORMANCE - Optimization, benchmarking
- RESEARCH - Starred repo analysis
- GOVERNANCE - Policy, quality gates

## Usage

Worklogs aggregated across all projects. See README.md for aggregation commands.
