## Primary References

### Specification & Documentation

1. **"Literate Programming"**
   - *Author:* Donald E. Knuth
   - *Publisher:* Stanford University, 1984
   - *Key Concept:* Code and documentation together
   - *Application:* AgilePlus kitty-specs as literate specifications

2. **"Behavior-Driven Development"**
   - *Author:* Dan North
   - *Year:* 2006
   - *Key Concepts:* Given-When-Then, shared understanding
   - *Application:* AgilePlus FR (Functional Requirements) structure

3. **"Living Documentation: Continuous Knowledge Sharing"**
   - *Author:* Cyrille Martraire
   - *Publisher:* Addison-Wesley, 2019
   - *Key Concepts:* Executable documentation, always up-to-date
   - *Application:* AgilePlus traced specs to tests

4. **"Docs-as-Code: The Missing Manual"**
   - *Author:* Anne Gentle
   - *Publisher:* O'Reilly, 2020
   - *Key Concepts:* Version-controlled docs, CI/CD for docs
   - *Application:* AgilePlus markdown specs in git

### Software Process

5. **"The Cathedral and the Bazaar"**
   - *Author:* Eric S. Raymond
   - *Year:* 1999
   - *Key Concepts:* Open source development models
   - *Application:* AgilePlus community contribution via specs

6. **"Design Patterns" (GoF)**
   - *Key Patterns:* Template Method (7-command workflow), State (spec states)
   - *Application:* AgilePlus specify → research → plan → implement → review → merge → ship

7. **"Lean Software Development: An Agile Toolkit"**
   - *Authors:* Mary Poppendieck, Tom Poppendieck
   - *Publisher:* Addison-Wesley, 2003
   - *Key Concepts:* Eliminate waste, amplify learning
   - *Application:* AgilePlus spec-first eliminates rework

9. **"The DevOps Handbook"**
   - *Authors:* Gene Kim, Jez Humble, Patrick Debois, John Willis
